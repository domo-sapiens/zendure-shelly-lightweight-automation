Tracking error

Two different faults, deliberately separated. Regulation error is how far grid power sits from target — mistuned gain shows up here as oscillation through zero. Saturation gap is what the battery was asked for minus what it delivered; non-zero means it could not comply, so the error is not a tuning problem. Reading only one of these cannot tell those apart.
