Marking measured vs derived — four proposals

Same live state in all four, so only the labelling differs. There are arguably three tiers, not two: values read straight off an instrument; values that are exact arithmetic over those readings; and values that additionally depend on a fitted constant. Proposals differ in whether that third tier is worth showing.

My recommendation: C. A footnote marker on only the derived values (A, B) leaves every unmarked number implicitly claiming to be measured — which is fine until someone asks "is SoC measured?" (it is not; the BMS estimates it). C labels everything, so nothing is claimed by omission, and it is the only one that separates exact arithmetic from depends on a fitted constant — the distinction that actually matters when a number looks wrong. D is the most complete but pushes the explanation away from the picture; it works well combined with C as an expandable detail.
